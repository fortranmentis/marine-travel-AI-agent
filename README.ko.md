# Marine Travel AI Agent · 바다결

[English](README.md) · [검증 범위](VALIDATION.md) · [개발 계획](docs/ROADMAP.md)

인천 가족 여행을 위한 **해양예보 기반 AI 일정 도우미**입니다.
TourAPI 관광정보, 국립해양조사원 생활해양예보지수, 기상청 단기예보를
결합하고 서버 Ollama의 Qwen 모델이 도구를 호출합니다.

## 현재 기능

- 영종·용유, 강화, 송도·도심 권역의 1~3일 자차 여행 초안
- 성인 수·자녀 나이·하루 여행 시간·원하는 활동 입력
- 관광 후보, 갯벌체험 예보 시간, 점심·환복·휴식 배치
- 일정 시간 고정, 관광지 제외, 대화로 수정 요청
- 출처·수집 시각·도구 호출 결과 확인, 장소별 지도 링크
- AI 응답 실패 시 규칙 기반 일정 제공

가족 구성은 입력·대화에 전달되지만, 연령별 체험장 적합성을 검증하는
목록은 아직 없습니다. 모든 일정은 **현장 확인이 필요한 검토용 초안**입니다.

## 실행

Python 3.11 이상이 필요합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

`.env`에서 다음을 설정합니다.

- `MARINE_CREDENTIALS_FILE`: API 키 문서 절대 경로
- `OLLAMA_BASE_URL`: 실제 Ollama 서버 주소와 포트
- `OLLAMA_MODEL`: 기본값 `qwen3.8:27b-mtp-q8_0`
- `OLLAMA_NUM_CTX`: 초기값 16384

키 문서는 `서비스명`, `엔드포인트 : ...`, `키 : ...` 세 줄을 서비스별로
빈 줄로 구분합니다. [영문 안내](README.md)에 예시가 있습니다.
국문 관광정보·단기예보·해양지수 8종의 키가 필요합니다.
관광사진은 점검 스크립트에서만 확인하며 현재 일정 화면에서는 사용하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m marine_agent.sync
.\run.ps1
```

브라우저에서 **http://127.0.0.1:8001** 을 엽니다. 현재 PC에는 서버 주소와
키 문서 경로를 로컬 `.env`에 설정했습니다. 키 값은 복사하지 않았습니다.
`.env`, `data/`, 가상환경, 실제 대화 결과는 Git에서 제외합니다.

수집은 전체 페이지를 순회하며 중복·누락을 검사합니다. 해양 자료 수집이
실패하면 기존 정상 스냅샷을 유지합니다. 매일 계획 전 수집 명령을 실행하세요.
서버는 인증 없는 로컬 개발용입니다.

## 추천 규칙과 한계

- 갯벌체험은 ‘좋음/매우좋음’ 지수와 체험 가능 시간을 함께 사용합니다.
- 준비·환복 각각 30분, 체험 60분, 관광 90분을 가정합니다.
- 예보 없음·전날 자료·나쁜 지수·폐장을 좋은 조건으로 해석하지 않습니다.
- 해수욕은 개장·연령·현장 조건 확인 기능이 없어 자동 배치하지 않습니다.
- 권역은 좌표 범위로 분류합니다. 인접 관광지에 해양지수를 전이하지 않습니다.
- 관광 후보는 직선거리로 좁힙니다. 60분 간격은 이동·휴식 가정이며 도로 경로는 미검증입니다.
- 운영시간·휴무·예약·어린이 이용 조건·특보·현장 통제는 미확인입니다.
- 문화시설 대안의 실내 여부와 영업시간은 개별 확인이 필요합니다.
- 기상청 예보는 권역의 대표 관광 후보 좌표로 조회합니다. 모든 방문지의 현지 날씨를 검증하지 않습니다.
- 숙박·식당 예약, 배편이 필요한 섬 여행은 지원하지 않습니다.
- AI 설명에는 오류가 있을 수 있어 일정 카드와 원본 자료를 함께 확인해야 합니다.
